Miasma supply chain toolkit: GitHub C2, credential harvesting, AI coding tool config poisoning

Miasma uses GitHub commit search as a C2 channel via three distinct search terms, delivering encrypted credentials, JS payloads, or remote Python commands. The kill chain: harvests secrets from AWS/Azure/GCP/Kubernetes and password managers; propagates via npm/PyPI/RubyGems OIDC tokens; SSH lateral movement; GitHub Actions orphan-commit hijacking; and injects malicious configuration into .claude/, .cursor/, .vscode/, and .gemini/ directories — covering 13 AI coding tools. Detection: hunt GitHub commits for the three C2 search terms; enforce OIDC token scope restrictions; monitor for binding.gyp injections in packages.

Why it matters: This is the first documented toolkit specifically designed to weaponise trust between developers and AI coding assistants. Any team using Claude Code, Cursor, or similar tools should audit agent config directories immediately.
sources: TLDR InfoSec [blurb only]
University of Nottingham: 40GB exfiltrated via PeopleSoft zero-day; part of 100+ organisation campaign

ShinyHunters compromised Oracle PeopleSoft via a zero-day gadget chain, exfiltrating 454,600 student records including passport numbers, billing records, addresses, and disability details. Confirmed as part of a broader campaign targeting 100+ organisations using chained zero-days and legacy vulnerabilities. Recommended actions: validate PeopleSoft patch versions, enforce IP allow-listing with MFA on admin accounts, monitor PSAPPSRV.LOG for anomalous SQL extraction.

Why it matters: The zero-day chain suggests the attacker group has systematic access to a PeopleSoft vulnerability class that most higher education institutions — and many enterprises — have not patched. This is an ongoing campaign, not an isolated breach.

Microsoft Exchange "Ghost-Sender": any email address spoofable, bypasses SPF/DKIM/DMARC — Microsoft won't fix

A one-line PowerShell command lets attackers send email from any internal or external address, including real CEO addresses with Outlook-resolved profile pictures, with no phishing indicators visible to recipients. SPF, DKIM, and DMARC checks all pass. Microsoft has classified this as an architectural limitation rather than a vulnerability. Immediate mitigations: disable Direct Send; deploy partner connector with IP/certificate validation; add a mail flow rule quarantining mail where X-MS-Exchange-Organization-AuthAs is not Internal from unexpected source IPs.

Why it matters: Microsoft's non-fix decision effectively makes authenticated email structurally untrustworthy for any organisation on Exchange. BEC (Business Email Compromise) attacks just got meaningfully easier.

Analyst Take

  • The trust stack is cracking simultaneously at multiple layers. Anthropic's hidden distillation guardrail, Microsoft's unfixed Exchange spoofing flaw, and the Miasma AI coding tool config-poisoning toolkit all landed in the same week. The pattern: systems trusted by default — model outputs, email authentication, AI coding assistant configurations — are now actively exploited or unilaterally degraded. The implicit trust budget developers have extended to AI tools is being priced and withdrawn.
  • Agentic financial autonomy is arriving faster than enterprise risk management. Visa + OpenAI agent cards, Coinbase for Agents, and x402 payments landed in a single news cycle. The infrastructure for AI agents to autonomously transact money is functionally complete. Most enterprise AI governance policies have not contemplated this scenario; legal and compliance teams need to catch up before an agent with spending authority is deployed in production.
  • The distribution battle is being fought through systems integrators, not benchmarks. Anthropic-TCS, OpenAI-Microsoft, Google-Gemini enterprise deals — frontier model competition is increasingly won or lost through channel relationships. MiMo Code beating Claude Code on evals doesn't matter if TCS is deploying Claude to 50,000 enterprise seats next quarter.
  • An open-source parallel stack for agentic AI is assembling fast. MiMo Code (agent coding), Agent Substrate (Kubernetes execution), SkillSpector (security scanning), AgentsView (cost tracking), Stack Overflow for Agents (knowledge) — the open-source AI agent layer is compounding. Combined with the trajectory suggesting frontier open-weights reach Fable 5 performance on 16GB RAM by 2029, the window for proprietary lock-in is compressing to roughly 2–3 years.
  • Physical infrastructure is the binding constraint, not algorithms. Oracle's $55.7B capex, Broadcom/Apollo/Blackstone's $35B XPV Platform (Thursday), and the DRAM/NAND shortage hitting IT budgets all converge on the same bottleneck. SpaceX's $75B IPO is partly a bet on Starlink as the delivery layer for global AI infrastructure. Whoever controls compute location — not model quality — wins the next phase.
