## HEADLINES

**Big Tech data center commitments cross $850B as enterprise AI spend accelerates** — Major cloud and tech firms have committed over $850B in future data center lease obligations, with Meta and Microsoft posting the largest increases as they lock up compute capacity ahead of demand. A parallel RBC survey of CIOs confirms enterprise AI budgets are accelerating and being treated as net-new spend rather than replacing existing software budgets; OpenAI remains the dominant provider among surveyed enterprise accounts. *Why it matters:* The infrastructure bet is now so large that any sustained slowdown in AI adoption would create stranded-asset risk at scale. The financial system has committed. (sources: TLDR IT, TLDR IT)

**DirtyClone makes Linux kernel root escalation trivially accessible** — CVE-2026-43503 (CVSS 8.8) is the fourth exploitable Linux kernel root escalation in six weeks. An unprivileged user with CAP\_NET\_ADMIN—available by default on Debian and Fedora via unprivileged user namespaces—can overwrite privileged binary auth logic (e.g., `/usr/bin/su`) by routing page-cache memory through an attacker-controlled IPsec tunnel. No disk writes, no logs. Ubuntu 24.04+ is protected via AppArmor. The May 21 mainline fix is available; if patching is not immediately possible, set `kernel.unprivileged_userns_clone=0` (disables IPsec and AFS). *Why it matters:* Four exploits in the DirtyFrag family within six weeks signals a systemic kernel code-quality problem. Any enterprise Linux fleet on Debian or Fedora with default namespace settings is exposed right now. (source: TLDR InfoSec)

**Model cost arbitrage becomes a product category** — Cognition's Devin Fusion reduces coding-agent costs 35% by dynamically routing between frontier and cheaper models within the same task, using a dual-agent main/sidekick architecture; Fable 5 integration pushes the reduction to 41%. Separately, Tokyo-based Sakana AI launched Fugu—93.2 on LiveCodeBench, $5/M input tokens—explicitly targeting demand displaced by the US Mythos export ban. Chinese firm 360 simultaneously disclosed Tulongfeng, claiming Mythos-class capability for cyber defense, alongside Yitianzhen for incident response. *Why it matters:* The export ban is accelerating Asian frontier model development and domestic multi-model optimization simultaneously. US labs may be ceding the "accessible tier" of high-end AI faster than anticipated. (sources: TLDR AI, TLDR IT)

## AI & RESEARCH

**DeepSeek open-sources DSpark, claims 85% LLM inference speedup** — A speculative-decoding-style scout runs ahead of the main model, proposes token paths, and lets the large model verify cheaply when guesses land. Open-sourced. *Why it matters:* If benchmark numbers hold in production, this is a meaningful cost lever independent of model routing—it works within a single model deployment. (source: TLDR AI)

**Amazon renegotiating Anthropic contract to per-token billing** — A shift from flat compute commitments to per-token pricing could substantially increase Amazon's costs depending on usage volume, and has prompted Amazon to explore cheaper AI alternatives. *Why it matters:* The Anthropic-Amazon relationship is more complex than a simple investment-for-compute deal. Pricing tension at this scale will shape both parties' product and partnership strategies. (source: TLDR main)

**The AI ecosystem is modularizing like the software stack** — A long-form piece argues that standardized inference APIs and the Transformer architecture are enabling open-weights models to compete with closed systems, disaggregating the AI stack much as UNIX and then Linux disaggregated proprietary computing. *Why it matters:* If modularization continues, value accrues to whoever owns training data, distribution, or integration—not the model itself. Closed-model moats compress. (sources: TLDR AI, TLDR main)

**Brain2Qwerty v2: 61% word accuracy from non-invasive EEG** — Meta AI trained on ~22,000 sentences from nine volunteers wearing MEG headsets, achieving 61% real-time word accuracy—up from 8% with prior non-invasive methods. Full training code and v1 dataset released on Hugging Face. *Why it matters:* Non-invasive BCI is crossing a threshold that historically precedes productization. (source: TLDR main)

**RL beyond verifiable domains** — The next scaling frontier for RL-based training is tasks that cannot be automatically graded: subjective quality, creative output, multi-step reasoning chains. Process reward models, constitutional AI-style feedback, and outcome-based proxies are the main approaches being explored. *Why it matters:* Verifiable domains have been the easy wins. Unlocking the rest is what would produce genuinely general-purpose systems. (source: TLDR AI)

**Cursor for iOS now in public beta** — Allows developers to launch and control cloud or local agents, receive updates via Live Activities, and merge PRs from mobile. (source: TLDR AI)

## DEV, DEVOPS & INFRA

**Russian FSB pivoting from MFA codes to Signal backup recovery keys** — FBI/CISA jointly name UNC5792 and UNC4221 as FSB operators phishing specifically for Signal Backup Recovery Keys by posing as automated support. A harvested key unlocks the full historical message archive and survives account recreation under the same phone number—durable surveillance. Rewards for Justice has attached a $10M bounty to UNC5792. *Why it matters:* Anyone who has Signal backups enabled and may have shared a recovery key in a phished session should treat that archive as potentially compromised and rotate. (source: TLDR InfoSec)

**Mozilla 0DIN: clean GitHub repos can redirect AI coding agents to attacker-controlled commands** — A working PoC hides a reverse shell three indirection layers deep: an ordinary-looking Python package errors, prompts the agent's auto-recovery logic to run `python3 -m axiom init`, which fetches an attacker-controlled value from a DNS TXT record and executes it as a shell command. No malicious code appears in static review; no single step trips automated analysis. *Why it matters:* Autonomous coding agents with outbound network access and auto-error-recovery behavior are a new attack surface that sandboxes and code review tooling are not yet built to address. Egress controls during setup and human approval for any command piping remotely fetched content are the mitigations. (source: TLDR InfoSec)

**NAIC breached via Oracle PeopleSoft zero-day, disrupting sector-wide rating functions** — The federal insurance regulator was breached June 11 (disclosed June 17) via a zero-day in PeopleSoft used for internal financial reporting, part of a multi-organization campaign. Several credit rating agencies paused feeds; NAIC temporarily suspended investment designation assignments. *Why it matters:* A back-office ERP zero-day disrupted sector-wide regulatory functions—financial infrastructure's attack surface extends well beyond core systems. PeopleSoft deployments across regulated industries should be treated as elevated risk. (source: TLDR InfoSec)

**Repo-jacking Anthropic's Claude plugin community: mostly mitigated, but gaps remain** — A researcher claimed a dangling GitHub namespace from a renamed account, recreated the targeted repo, and demonstrated the plugin install UI lands users on the attacker-controlled page. The code-install path was protected by SHA pinning on marketplace entries—but the researcher flagged that bot-driven SHA-refresh PRs could potentially ingest a SHA from a malicious commit. Anthropic classified as out-of-scope (dependency hijacking excluded). Five dangling namespaces remain claimable. *Why it matters:* Marketplaces relying on UI prompts as the primary trust signal are weak against namespace squatting. SHA pinning is necessary but not sufficient. (source: TLDR InfoSec)

**Meta open-sources Astryx design system** — Eight years in development, powers 13,000+ Meta applications, 150+ accessible components, architecture-agnostic with no styling lock-in, and an API designed for human and AI co-authorship. (source: TLDR Dev)

**Formal verification becoming accessible via AI tooling** — ACM Queue piece argues AI removes the prohibitive cost of writing proofs, making formal verification economically viable for ordinary business logic—not just safety-critical code. *Why it matters:* If correctness proofs become a standard engineering artifact, the risk profile of deployed software changes materially. (source: TLDR Dev)

**AWS AMI watermarks now available** — Identifiers embedded in approved private machine images follow derived AMIs across copies, regions, and shared accounts, making provenance enforcement tractable at scale. (source: TLDR IT)

## ANALYST TAKE

- **The export ban is producing the opposite of its intended effect.** Restricting Mythos access was presumably aimed at preserving US AI advantage. Instead it is producing faster-than-expected frontier development in Japan (Fugu) and China (Tulongfeng), at competitive performance points and lower price points. US labs have a narrowing window before non-US models cover the performance curve at accessible pricing.

- **Multi-model routing is the next infrastructure layer.** Devin Fusion, DSpark, and the "economy of tokens" thesis all point in the same direction: the valuable abstraction is not a single model but the orchestration logic that routes between them on cost and capability. The routing layer captures the margin that frontier models used to command.

- **AI agent attack surface is outpacing defenses.** Three distinct attack vectors appeared this week: Signal recovery key phishing, GitHub repo-jacking of AI plugin marketplaces, and clean-repo malware via agent auto-error-recovery. All have working PoCs or active exploitation. Identity governance, sandboxed execution, and egress controls are not yet standard practice for teams deploying autonomous agents.

- **The software bottleneck has moved up the stack.** GitLab research, VentureBeat, and TLDR Product independently converge on the same observation: AI has largely solved code generation; it has not solved task specification. The constraint is now product judgment and evaluation design. "It's hard to eval" is a product smell, not a model limitation.

- **Bitcoin's technical setup echoes 2022 cycle bottom markers.** Realized loss metrics, RSI divergences, and historical seasonality are aligning. Not a prediction—but the structural indicators that preceded prior reversals are present. The regulatory catalyst (CLARITY Act) just became less certain on the same day.
