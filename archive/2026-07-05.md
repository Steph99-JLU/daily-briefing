(sources: TLDR) [verified — Reuters exclusive, corroborated by Yahoo/TechCrunch]

**Zero-click RCE flaws let prompt injection take over Cursor.** Security researchers disclosed two critical vulnerabilities (CVE-2026-50548, CVE-2026-50549, CVSS 9.8) in the Cursor AI coding IDE, dubbed "DUNESLIDE." A poisoned MCP server response or web-search result could hijack Cursor's agent into overwriting its own sandbox binary, escalating from sandboxed commands to full unsandboxed code execution — no click required. Cursor initially disputed the report's scope in February before shipping fixes across versions 3.0 (April) and a follow-up patch in June.
Why it matters: the clearest demonstration yet that agentic coding tools inherit prompt injection as a genuine remote-code-execution vector, not just a prompt-hygiene problem. Patch Cursor now if you haven't.
(sources: TLDR Dev) [verified — The Hacker News, CSO Online, NVD]

**Cloudflare flips the default on AI crawlers.** From 15 September, Cloudflare will default-block "mixed-use" AI crawlers — bots blending search, agent and training functions — from any ad-hosting page unless the site owner opts out, applied across free-tier and new customers. It pairs with a pay-per-use model (launch partners Ceramic.ai and You.com) that pays publishers only when their content actually appears in an AI-generated answer.
Why it matters: flips the web's default from opt-out to opt-in for a meaningful share of global traffic, directly changing the unit economics of AI training and retrieval.
(sources: TLDR, TLDR IT) [verified via first-party Cloudflare framing, reported consistently across independent outlets]

## DEV, DEVOPS & INFRA

**An AI agent ran a ransomware attack with no human in the loop.** Sysdig documented "JADEPUFFER" — what it says is the first ransomware attack executed end-to-end by an autonomous AI agent. The agent exploited a known Langflow RCE (CVE-2025-3248) to harvest credentials, pivoted into a production MySQL/Nacos server via a 2021 auth-bypass bug, encrypted 1,342 configuration items, and left a ransom note whose decryption key was never saved — self-correcting a failed login within 31 seconds along the way.
Why it matters: a category shift from AI-assisted to AI-operated attacks. The broken ransom key suggests tooling is currently ahead of operator tradecraft — that gap will close.
(sources: TLDR IT) [blurb only — corroborated across multiple security outlets, primary source not directly fetchable this run]

**Google and the FBI dismantle a 2-million-device proxy botnet.** Google's Threat Intelligence Group, with the FBI and Lumen, took down NetNut ("Popa"), a residential proxy network built on at least 2 million compromised phones, TVs and streaming boxes. In one week in June, Google observed 316 distinct criminal and espionage clusters routing traffic through it; Google disabled the network's control accounts and the FBI seized its domain.
Why it matters: a rare, large-scale multi-party infrastructure takedown rather than another routine advisory.
(sources: TLDR Information Security) [blurb only — primary source not directly fetchable this run]

**A SharePoint RCE Microsoft called "less likely" to be exploited is now under active attack.** CISA added CVE-2026-45659 (CVSS 8.8, deserialization RCE, triggerable by any authenticated Site Member) to its Known Exploited Vulnerabilities catalogue, contradicting Microsoft's own May assessment that exploitation was unlikely. Federal agencies face a 4 July remediation deadline.
Why it matters: another vendor severity call overtaken by real-world exploitation. Patch SharePoint on-prem now if you haven't.
(sources: TLDR Information Security) [verified — CISA KEV catalogue, The Register]

**Apple ships a native MCP server inside Safari.** Safari Technology Preview 247 adds a local-only Model Context Protocol server, letting any MCP-compatible agent connect to a live Safari window to read the DOM, take screenshots, inspect network/console output, run JavaScript and check accessibility — no data leaves the machine, and the developer chooses which agent to trust.
Why it matters: Apple's first native hook for agentic coding tools inside a shipping browser engine, following MCP's donation to the Linux Foundation — expect pressure on Chrome and Firefox to match it.
(sources: TLDR Dev, TLDR IT) [blurb only — primary sources not directly fetchable this run]
