**DeepMind publishes AI Control Roadmap for system-level agent security** — DeepMind has released a structured roadmap for AI control at the systems level, focused on containing agents through technical mechanisms rather than relying solely on model alignment. The document addresses multi-agent deployments where a single mis-aligned or compromised component can propagate actions across pipelines. *Why it matters:* The framing shifts enterprise security conversations from "is this model safe?" to "is the system containing this model correctly designed?" — a more tractable and auditable standard. **MosaicLeaks: research agents leak private data; PA-DR cuts exposure from 34% to 9.9%** — A research paper termed MosaicLeaks demonstrates that agents performing document retrieval and analysis tasks inadvertently leak private details from retrieved documents into outputs accessible to other users or sessions. A proposed mitigation called Privacy-Aware Document Retrieval (PA-DR) reduces the leakage rate from 34% to 9.9% without significant accuracy loss. *Why it matters:* Multi-tenant agent deployments — particularly in enterprise RAG pipelines — carry a data boundary risk that is underappreciated relative to the current pace of deployment. (sources: TLDR AI) [blurb only]

Two known malicious packages: `ExarGD.vsblack@0.0.1` and `noellee-doc/flint-debug@0.1.1`. *Why it matters:* WebAssembly as a malware delivery format is difficult to scan with conventional extension security tooling; Open VSX's lighter review process compared to the VS Code Marketplace makes it a soft target. ## ANALYST TAKE

- **Google's retention problem is structural, not temporary.** Noam Shazeer's departure to OpenAI, combined with earlier exits of other senior researchers, suggests that Google's equity-and-prestige retention model is failing at the frontier tier where the most consequential research decisions are made. Google still has the data and infrastructure advantages; it is losing the people advantage.

- **The Microsoft Claude Code rollback is the agentic coding industry's first enterprise stress test.** The $2K/engineer/month figure will become a reference point in every enterprise AI procurement conversation for the next 12 months. Vendors that cannot demonstrate clear ROI against that ceiling will struggle to close deals. The GitHub shift to usage-based billing on the same week is not a coincidence.

- **This week's security incidents all share one root cause: agents with write access and insufficient containment.** The Kiro AWS outage (delete permissions), GlassWASM (WebAssembly in extension sandboxes), 10,000 GitHub trojan repos (trusted supply chain), and the Salesforce OAuth breach (unconstrained scope) are four different attack vectors producing the same outcome. The pattern is agent or automated system trust exceeding the monitoring and rollback infrastructure surrounding it.

- **The agent infrastructure layer is consolidating around a handful of competing standards.** MCP Enterprise Authorization, Snowflake ARD, S3 Annotations, Vercel Connect, and Stack Overflow for Agents all shipped in the same week. This is not coincidence — it reflects a race among platform vendors to define the authentication, data access, and knowledge interfaces that agents will use in production. Which standards win will determine which platforms sit in the critical path of enterprise AI.

- **U.S. crypto regulation is bifurcating sharply.** Stablecoins are getting regulatory clarity (GENIUS Act framework, MiCA-equivalent positioning). CBDCs are being blocked by statute. Prediction markets are under state-level legal attack. The net effect is a regulatory environment that favors private-sector dollar-denominated digital assets while closing off public alternatives and constraining speculative applications.
